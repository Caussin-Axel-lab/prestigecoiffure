# Prestige Coiffure — Site web

Site web one-page pour Prestige Coiffure, salon de coiffure à Chalon-sur-Saône.

## Comment l'utiliser

### Pour visualiser le site localement

1. Garde les **trois fichiers dans le même dossier** :
   - `index.html`
   - `style.css`
   - `script.js`
2. Double-clique sur `index.html` — le site s'ouvre dans ton navigateur.

Pas besoin d'installer quoi que ce soit. Une connexion internet est nécessaire pour charger :
- Les polices Google Fonts (Cormorant Garamond, Manrope, JetBrains Mono)
- Les images d'illustration Unsplash
- La carte Google Maps intégrée

### Pour modifier le contenu

- **Textes, équipe, prestations** → `index.html`
- **Couleurs, typographie, mise en page** → `style.css`
- **Animations, menu mobile** → `script.js`

Tu peux ouvrir ces fichiers dans n'importe quel éditeur (Notepad++, VSCode, Sublime, ou même TextEdit / le Bloc-notes).

### Pour mettre en ligne

Le site est prêt à être hébergé tel quel. Tu peux :

- L'uploader sur un hébergement classique (OVH, Hostinger, etc.) via FTP
- L'héberger gratuitement sur **Netlify** (drag & drop du dossier sur netlify.com/drop)
- L'héberger gratuitement sur **GitHub Pages** ou **Cloudflare Pages**
- L'intégrer dans un site existant

## À compléter avant mise en ligne

1. **Tarifs** — remplacer les mentions `[tarif Planity]` par les vrais tarifs (ou tout laisser pointer vers Planity)
2. **Photos** — remplacer les photos Unsplash (illustration) par les vraies photos pro du salon
3. **Portraits équipe** — remplacer les placeholders (lettres) par les portraits réels
4. **Mentions légales** — créer les pages dédiées « Mentions légales » et « Politique de confidentialité »
5. **Tracking** — ajouter Google Analytics ou Plausible si souhaité

## Identité technique

- **Mobile-first**, responsive (s'adapte à toutes les tailles d'écran)
- **One-page** (toutes les sections sur une seule page, navigation par ancres)
- **Vanilla HTML/CSS/JS** (pas de framework, simple à maintenir)
- **Polices web** chargées depuis Google Fonts
- **Carte intégrée** sans clé API requise (embed Google Maps standard)
- **CTAs** pointant vers Planity, Instagram, Facebook, téléphone, Google Maps

## Polices

- **Cormorant Garamond** — titres éditoriaux et mises en valeur (serif)
- **Manrope** — corps de texte et navigation (sans-serif)
- **JetBrains Mono** — petits labels uppercase (monospace)
